# Commander Companion v0.5.1 — Hotfix 1

## Fixes
- Centers text and icon/text groups in interactive buttons and control boxes.
- Strengthens outlines on important enabled actions using the existing Commander Companion visual language.
- Makes `dynamicActionFields` compatibility handling null-safe so an optional/moved action panel cannot abort startup.
- Draw confirmation actions now take a direct path instead of depending on the legacy hidden action popup.
- Adds Card Finder type categories: All, Lands, Creatures, Artifacts, Enchantments, Instants, Sorceries, Planeswalkers, Battles, Tokens.
- Adds the same category filtering to Play/Card selection and Deck Builder Add Card search.

## Visual scope
No layout redesign, icon redesign, mana redesign, menu redesign, or player-card restructuring is included in this hotfix.
