# Commander Companion v0.5.2 — CLEAN

This is the cleaned current-release package.

## GitHub Pages deployment
For the live app, `index.html` is the production entry point. Upload it at the repository root
(or replace the existing root `index.html`).

The remaining files are release/reference documents:
- `VISUAL-MASTER-V0.5.2.png` — frozen visual authority
- `VISUAL-MASTER-LOCK.md` — layout lock rules
- `RELEASE-STATUS.md` — current consolidated release notes
- `KNOWN_ISSUES.md` — currently tracked issues
- `TEST_REPORT.md` — current retained test record

Historical RCs, superseded hotfix notes, duplicate HTML entry points, and stale previews were
intentionally removed to prevent future builds from accidentally referencing obsolete material.
